# LuponResolve

A starter frontend for the LuponResolve barangay dispute and case management portal.

## Current stack

- HTML
- Plain CSS
- Vanilla JavaScript

## Run the project

1. Extract the ZIP file.
2. Open the `LuponResolve` folder in Visual Studio Code.
3. Open `index.html` in your browser.

You can also use the VS Code Live Server extension if you have it installed.

## Folder structure

```text
LuponResolve/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── README.md
```

## Current milestone

Milestone 1: Initial homepage and frontend foundation.

The complaint form, Pre-Screener, dashboards, backend, database, and authentication
will be added in later steps. This starter does not yet store or submit real complaints.
